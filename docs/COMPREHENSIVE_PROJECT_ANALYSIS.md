| 技术 | 版本 | 评价 |

| React | 18.x | ✅ 主流框架，生态成熟 |

| Recharts | 2.x | ✅ React原生图表库 |
| @microsoft/signalr | 8.x | ✅ 官方SignalR客户端 |

**前端技术栈评价**: 工业软件选用Ant Design是明智之选，提供了丰富的企业级组件。Zustand相比Redux更简洁，适合中小型项目。
