# Synthetic Demo Data

Run `node tools/demo/init.mjs`, install backend/frontend dependencies, then start
`node tools/demo/run.mjs` and `node tools/demo/run.mjs ui` in two terminals from the repository root.
The helper generates random local credentials and refuses to replace an existing `.env`.

One synthetic motor emits Temperature, Vibration, RPM, Current and Voltage each second. A repeatable
60-second cycle starts with ten seconds above the 85 °C demo threshold. Five minutes of recent history
are inserted on startup. The real threshold evaluator creates an alarm; API health calculations use
the same synthetic points. This is a software demonstration, not a model of a real motor's safety limits.

Open Dashboard/Data Explorer/Alarm Management/Health Assessment after signing in with `.env`
credentials. If an alarm is acknowledged, it remains stored; a new one is deduplicated until the
existing one is closed. Health history is generated by the normal API background service.

`node tools/demo/smoke.mjs` verifies real HTTP behavior. `DEMO_BASE_URL` can override port/host for the
smoke script. `DOTNET_EXE` can point the run helper at a privately installed .NET SDK executable.
The API validates Development + Sqlite before enabling the demo. No protocol client is used, and this
is not an OPC UA mock server or EtherNet/IP simulator.
